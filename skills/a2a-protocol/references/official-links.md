# Official A2A Links

Open these URLs when exact behavior, wording, or current package versions matter.

## Protocol

- Specification: `https://a2a-protocol.org/latest/specification/`
- Python SDK API index: `https://a2a-protocol.org/latest/sdk/python/api/index.html`
- .NET package overview: `https://www.nuget.org/packages/A2A`

## Source Repositories

- Python SDK repository: `https://github.com/a2aproject/a2a-python`
- .NET SDK repository: `https://github.com/a2aproject/a2a-dotnet`

## Use Each Source For

- Use the specification for protocol semantics, bindings, wire rules, task states, and agent card requirements.
- Use the Python API docs for package layout and module-level SDK surfaces.
- Use the Python repository for installation notes, compatibility tables, and sample links.
- Use the .NET repository and package pages for class names, hosting patterns, and package-version-specific guidance.

## Version Discipline

- Re-open the live links when the user asks for the latest status.
- In .NET work, prefer the exact version page or the project's `PackageReference` over the generic package landing page.
